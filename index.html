🏫 Misi Masalah Nyata

Sekolahmu memiliki 400 siswa dan aktif selama 20 hari sekolah dalam sebulan. Pihak sekolah ingin memperkirakan total sampah plastik yang dihasilkan per bulan.

Pertanyaan: Besaran mana yang nilainya belum diketahui secara pasti dan dapat diwakili oleh variabel x?

Jumlah Siswa (400)
Hari Sekolah (20 Hari)
Sampah per siswa per hari (x gram)

🧩 Model Builder

1. Sampah seluruh siswa dalam 1 hari = 400 × x = 400x

2. Sampah seluruh siswa dalam 20 hari = 400x × 20 = 8000x

Model Utama: S = 8000x

Evaluasi Aljabar (Substitusi): Jika pengukuran menunjukkan rata-rata setiap siswa menghasilkan x = 25 gram sampah per hari, berapa total sampah per bulan (S)?

🎛️ Eco Simulator

Model dikembangkan untuk menguji strategi pengurangan sampah: S = 20n(x - r)

Dimana: n = Jumlah siswa, x = Sampah dasar (g), r = Pengurangan sampah (g)

HASIL MODEL SIMULASI

Sampah Awal: 200 kg

Sampah Akhir: 200 kg

Persentase Reduksi: 0%

🎯 Strategy Lab

Tantangan Kepala Sekolah: Kurangi sampah sekolah minimal 30% dari kondisi awal!

Pilih kombinasi strategi berikut untuk meningkatkan nilai pengurangan (r):

🥤 Program Tumbler

Mengurangi 3g sampah/siswa

🛍️ Kantin Minim Plastik

Mengurangi 5g sampah/siswa

📢 Kampanye Edukasi

Mengurangi 2g sampah/siswa

Total Reduksi (r): 0 gram/siswa | Persentase: 0%

⚠️ Reality Check & Revisi Model

Data Baru Lapangan: Ternyata hanya 80% (0,8) siswa yang konsisten menjalankan program lingkungan tersebut.

Model matematika harus direvisi untuk memperhitungkan tingkat kepatuhan tersebut:

Model Revisi: S = 20n(x - 0.8r)
